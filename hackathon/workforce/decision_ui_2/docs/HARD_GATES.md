# Hard gates

| Gate | Status on public face |
|---|---|
| No standard desktop horizontal scrolling | Enforced in CSS + Playwright |
| No technical IDs in primary face | Question prompts only; no internal index names |
| No fake temporal values | Public magnitudes and series are `null` / pending |
| No chance-of-harm number | Denied in the direction rail |
| No wet-bulb globe number | Denied; acronym not printed |
| No accumulated-exposure number | Not present |
| No intervention success claim | Stamp + contract flag |
| No “current” unless live | Copy says selected / dated, not live |
| Zero-context reviewer can infer question, period, baseline, result, direction | Ledger + chart chrome + question heading |

## Files not touched

This package does not edit `apps/api`, analytics engines, replay evidence, or the existing `apps/web` judge shell. Those remain the validated product on `integration/judge-ready-product`.
